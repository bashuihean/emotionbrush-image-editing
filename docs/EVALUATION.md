# 评测口径与历史结果

历史指定测试共 3299 组原图/参考图/情绪条件。以下仅公开聚合结果，未公开私有测试样本或权重，
因此不是第三方已独立复现的公开基准成绩。

| 指标 | 历史结果 |
|---|---:|
| 新 Emo-A（固定外观分类器 B） | 60.3516%（1991/3299） |
| 旧 ResNet 情绪分类准确率 | 22.9160% |
| SSIM（代码中的 11×11 均值窗口实现） | 0.636162 |
| CLIP-I | 0.915316 |
| DINO 内容相似度 | 0.887946 |
| 旧流程 ESMI 兼容值 | 0.325718 |

分类器 A：ResNet18 冻结外观骨干＋参考图标签训练的分类头，用于情绪监督。
分类器 B：ResNet34 冻结外观骨干＋独立训练的分类头，生成器训练中固定，不向生成器提供 B 的梯度。
新 Emo-A 是 B 预测生成图的类别与目标类别相同的比例，不是生成质量总分。
同一图片在新分类器与旧分类器上的判断可能不同，不能把两套准确率混用。

测试目录虽然名为 Original_405，历史执行按全部 415 张原图匹配参考图，
得到 3299 组，缺少 21 个组合。没有按原论文 405 张去重协议重算。
本项目分数与客户原表 20.22% 既有分类器差异，也有测试协议差异，不应声称同协议提升至 60%。

历史 ESMI 兼容实现将目标类别概率改善与显著区域变化集中度平均。
其中结构项不是主体保持率，数值越高不能直接理解为主体越完整。
遗留评测需要额外的兼容分类器权重；未提供该权重时不能复现旧 ESMI。

最终历史训练使用前代内容/编辑权重和短程合并版检查点热启动，再进行三轮编辑训练。
本仓库提供从头执行阶段的入口，但不提供这些历史权重；不能承诺从头训练自动得到同一结果。
目前只完成发布包的静态检查与公开文件扫描，没有在新环境重新做完整 GPU 训练。
